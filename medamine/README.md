# Announcement Bar for Odoo 17

Display a fully customizable announcement bar at the top of your Odoo website.

## Features

- **Rich-text editor** — write your message with bold, italic, links and more
- **Color picker** — choose background and text color visually
- **Call-to-action button** — optional button with custom label and URL
- **Closable bar** — visitors can dismiss it; the choice is remembered for the session
- **Scheduled visibility** — set start/end dates for automatic display
- **Multi-website** — target a specific website or all sites
- **Translations** — message and button label are translatable per language
- **Ordering** — manage multiple announcements with drag & drop sequence

## Installation

1. Copy the `medamine` folder into your Odoo addons path
2. Update the apps list
3. Install **Announcement Bar**

## Usage

Go to **Website → Configuration → Announcement Bar**, create a new record, fill in your message and settings, then set it to **Active**.
