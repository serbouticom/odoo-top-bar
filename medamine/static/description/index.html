📢 Announcement Bar

Display a beautiful, customizable announcement bar at the top of your Odoo website — in minutes.

✨ Key Features

🎨

Full Color Customization

Pick any background and text color via a visual color picker to match your brand perfectly.

✍️

Rich Text Editor

Write your message with bold, italic, links and more using the built-in HTML editor.

🔗

Call-to-Action Button

Add an optional button with a custom label and URL to drive clicks and conversions.

❌

Closable Bar

Allow visitors to dismiss the bar. The choice is remembered for the session — no annoying repeat.

📅

Scheduled Visibility

Set a start and end date so the bar appears only during your campaign period automatically.

🌐

Multi-Website Support

Target a specific website or display on all sites. Perfect for multi-brand Odoo setups.

🚀 How to Use

1

Install the module

Install Announcement Bar from the Odoo Apps store in your Odoo 17 instance.

2

Go to Website → Configuration → Announcement Bar

A new menu entry appears under your website configuration section.

3

Create and customize your announcement

Write your message, choose colors, add a CTA button, and optionally set a schedule.

4

Activate and go live instantly

Toggle the bar to active — it appears immediately at the top of your website.
